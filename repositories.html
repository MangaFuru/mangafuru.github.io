Repository 與外部來源Repositories and external sources

只有已經取得可信 Repository 網址、並知道自己要連接哪個來源時，才需要這篇。You need this guide only when you already have a trusted repository URL and know which source you want to connect.

Repository 不是漫畫網站，也不包含漫畫。它是一份可安裝「來源連接器」的索引。來源安裝後，MangaFuru 才能依該來源的規則連接外部服務。A repository is not a manga website and contains no manga. It is an index of installable source connectors. After a source is installed, MangaFuru can connect to an external service according to that source's rules.

01什麼時候才需要 Repository？When do you need a repository?

只有要安裝外部來源時才需要。以下兩種情況完全不需要 Repository：You need one only to install an external source. These two paths do not use repositories at all:

  • 從「檔案」匯入自己的 EPUB、PDF 或 CBZ。Import your own EPUB, PDF, or CBZ from Files.
  • 連接你已經自行架設的 Komga 伺服器。Connect a Komga server you already host yourself.
如果你不知道 Repository 網址要從哪裡取得，先不要新增。MangaFuru 不提供或推薦來源清單。If you do not know where a repository URL should come from, do not add one yet. MangaFuru does not provide or recommend source lists.

02加入前先確認三件事Check three things before adding

  1. 1你信任提供者。Repository 會提供可執行的來源套件，不只是文字清單；不要加入來路不明的網址。You trust the provider. A repository distributes executable source packages, not only text metadata. Do not add unknown URLs.
  2. 2你有權使用相關服務與內容。Repository 存在不代表其中每個來源都適合你的所在地、帳號或使用情境。You have the right to use the service and content. A listed source is not automatically appropriate for your region, account, or use case.
  3. 3你拿到的是完整相容網址。通常會是 HTTPS 網址，並以 index.min.json 結尾。You have the complete compatible URL. It is normally an HTTPS URL ending in index.min.json.

03在 MangaFuru 加入 RepositoryAdd a repository in MangaFuru

探索 → 右上角 ＋ → Sources → 頁面底部「新增自訂 Repository URL」Browse → top-right + → Sources → “Add Custom Repository URL” at the bottom

  1. 1閱讀外部來源提醒。第一次加入時，確認三項聲明後才能繼續。Review the external-source notice. The first time you add one, acknowledge all three statements before continuing.
  2. 2輸入辨識名稱。名稱只供你自己辨認，不會改變遠端內容。Enter a label. The name is only for your own reference and does not change remote content.
  3. 3貼上完整網址並確認新增。MangaFuru 會先檢查網址與索引格式；成功後 Repository 會出現在清單。Paste the full URL and confirm. MangaFuru checks the URL and index format first; after success, the repository appears in the list.

04安裝、更新與移除來源Install, update, and remove sources

  1. 1打開剛加入的 Repository。你會看到它提供的可用來源；可用搜尋與篩選縮小範圍。Open the repository you added. You will see its available sources; use search and filters to narrow the list.
  2. 2在需要的來源旁點「新增」。等待安裝完成，再回到「探索」開啟來源。Tap Add beside the source you need. Wait for installation to finish, then return to Browse and open the source.
  3. 3有新版時使用更新動作。來源網站改動時，通常需要由套件提供者發布新版；MangaFuru 無法保證第三方服務永久相容。Use Update when a newer version appears. Website changes normally require the package provider to publish an update; MangaFuru cannot guarantee permanent third-party compatibility.
  4. 4不再使用時向左滑動移除。移除來源前，先確認書庫與備份中是否仍有依賴該來源的作品。Swipe left to remove a source you no longer use. First check whether your library or backup still contains titles that depend on it.
目前不支援直接選取 APK 安裝。外部來源必須透過相容 Repository 加入；本機檔案與 Komga 則走各自的內建流程。Direct APK file installation is not currently supported. External sources must be added through a compatible repository; local files and Komga use their own built-in flows.

05安全與責任Safety and responsibility

  • 優先使用 HTTPS，不要為未知來源開啟不安全 HTTP。Prefer HTTPS and do not enable insecure HTTP for an unknown source.
  • 登入、token、cookie 與網站驗證只應交給你信任的來源。Provide logins, tokens, cookies, or website verification only to sources you trust.
  • 不要在公開 issue 貼出帳密、完整 cookie、私密 token 或付費內容。Never post credentials, full cookies, private tokens, or paid content in a public issue.
  • 來源失效可能是第三方服務改版、下線、限制地區或變更條款，不一定是 App 問題。A source can fail because a third-party service changed, went offline, restricted regions, or changed its terms; it is not always an app problem.

如果你要發布自己開發的來源，請接著閱讀 開發與發布自己的來源。To publish a source you developed yourself, continue to Develop and publish your own source.
