第一次使用New to MangaFuru

先找到你要讀的內容First, find what you want to read

MangaFuru 是閱讀器，不是線上漫畫商店。App 不會預先附漫畫，你需要加入自己有權閱讀的內容。 MangaFuru is a reader, not an online manga store. It comes with no bundled catalog, so you add content you have the right to read.

先安裝 MangaFuruInstall MangaFuru first

已於 App Store 上架，需要 iOS 18.6 或以上版本。Available on the App Store. Requires iOS 18.6 or later.

01匯入 EPUB、PDF 或 CBZImport EPUB, PDF, or CBZ

最簡單的開始方式：先把 MangaFuru 當成自己的檔案閱讀器。The easiest start: use MangaFuru as a reader for your own files.

  1. 1打開「探索」。點畫面底部的「探索」，再點右上角＋。你會進入管理內容位置的 Sources 畫面。Open Browse. Tap Browse at the bottom, then tap the top-right +. This opens Sources, where MangaFuru manages content locations.
  2. 2開啟「本機來源」。在「可用」區找到本機來源並點「新增」。可以把它想成專門放你自己檔案的書架。Enable Local Source. Find Local Source under Available and tap Add. Think of it as a shelf for your own files.
  3. 3選一本書。回到探索，打開本機來源，點右上角＋，從「檔案」選取你自己的 EPUB、PDF 或 CBZ。Choose a book. Return to Browse, open Local Source, tap the top-right +, and select your EPUB, PDF, or CBZ from Files.
  4. 4開始閱讀或加入書庫。匯入後先點開作品即可閱讀；如果想長期保留在首頁，再從作品詳情加入書庫。匯入本身不會自動收藏。Read it or add it to Library. Open the imported title to read. If you want it kept on your home screen, add it to Library from the title detail. Importing alone does not auto-save it there.

02連接你自架的 KomgaConnect your self-hosted Komga

Komga 是一套由你自行架設的數位書庫；如果你沒有在使用 Komga，可以直接跳過這段。Komga is a digital library you host yourself. If you do not already use Komga, you can skip this section.

  1. 1前往 Sources。從底部「探索」點右上角＋，再點工具列上的伺服器新增按鈕。Komga 已內建，不需要另外安裝。Go to Sources. From Browse, tap the top-right +, then tap the add-server button in the toolbar. Komga is built in, so there is nothing else to install.
  2. 2填入連線資料。輸入顯示名稱、伺服器位址，以及伺服器需要的帳號與密碼；需要額外欄位時展開進階設定。Enter connection details. Add a display name, server address, and any username and password your server requires; open Advanced for additional fields.
  3. 3點「連接」。驗證成功後，伺服器會成為一個獨立來源；回到探索即可打開書庫。MangaFuru 最多可保留三個 Komga 連線。Tap Connect. After validation, the server appears as its own source; return to Browse to open the library. MangaFuru supports up to three Komga connections.
MangaFuru 只是讀取端。伺服器可用性、帳號、TLS 與內容都由你自己的 Komga 環境負責。MangaFuru is only the reader. Server availability, accounts, TLS, and content remain the responsibility of your own Komga environment.

03進階：連接其他來源Advanced: connect another source

第一次使用可以先跳過。只有你已經知道要使用哪個外部來源時，才需要這段。New users can skip this. You need it only when you already know which external source you want to use.

內容來源（Source）是 MangaFuru 讀取內容的連接方式，例如本機檔案、你的 Komga，或你自行選擇的其他服務。A content source is a connection MangaFuru reads from, such as local files, your Komga, or another service you choose.

Repository只是一份「有哪些外部來源可以安裝」的清單，本身不是漫畫內容。讀本機檔案或 Komga 時完全不需要它。A repository is only a list of external source connectors available to install; it is not manga content. Local files and Komga do not need one.

  1. 1準備 Repository 網址。MangaFuru 不提供、不推薦來源清單；請只使用你信任、且有權存取的 Repository。Prepare a repository URL. MangaFuru does not provide or recommend source lists. Use only a repository you trust and have the right to access.
  2. 2新增 Repository。從 Sources 頁底部進入新增流程，閱讀並同意外部來源提醒，再填入名稱與網址。Add the repository. Start the add flow from the bottom of Sources, review and accept the external-source notice, then enter its name and URL.
  3. 3安裝來源。開啟剛加入的 Repository，在可用來源旁點「新增」；完成後回到探索開啟來源。Install a source. Open the repository you just added and tap Add beside an available source, then return to Browse to open it.
  4. 4完成來源專屬設定。登入、mirror、token 或網站驗證若有需要，都從該來源的設定頁依服務要求處理。Finish source-specific setup. If login, a mirror, token, or website verification is required, handle it from that source's settings as the service requires.

04整理書庫並接著讀Organize your library and resume

  1. 1從作品詳情做選擇。長期追蹤的作品加入書庫；還沒決定的內容可以先放到稍後閱讀。Choose from the title detail. Add long-term reads to Library, or save undecided titles to Read Later.
  2. 2選擇閱讀方式。閱讀器支援直向 webtoon、分頁與由右至左模式；依內容調整即可。Choose a reading mode. The reader supports vertical webtoon, paged, and right-to-left modes. Pick what fits the content.
  3. 3從任何入口續讀。書庫、稍後閱讀與閱讀歷史都會接回作品；進度會保存在裝置上，讓你從上次位置繼續。Resume from any entry point. Library, Read Later, and History all lead back to the title; progress is stored on your device so you can continue where you stopped.

05備份與換機前準備Back up before moving devices

設定 → 備份與同步Settings → Backup & Sync

  1. 1選擇備份項目。依需要包含書庫、閱讀進度、來源與設定。Choose backup categories. Include your library, reading progress, sources, and settings as needed.
  2. 2匯出並妥善保存。使用「立即備份」建立檔案，存到你控制的位置。備份不包含已下載的漫畫圖片。Export and store it safely. Use Back Up Now to create a file and save it somewhere you control. Downloaded manga images are not included.
  3. 3在新裝置還原。安裝 MangaFuru 後回到同一頁選擇還原；完成後再重新下載離線內容。Restore on the new device. Install MangaFuru, return to the same page, and choose Restore; download offline content again afterward.

06排錯與回報問題Troubleshoot and report an issue

  1. 1先直接開啟失敗內容。若章節無法線上閱讀，下載通常也不會成功；先確認來源或伺服器目前可連線。Open the failing content directly first. If a chapter cannot be read online, its download usually cannot succeed either. Confirm the source or server is reachable.
  2. 2確認需要的設定。檢查登入、來源設定、網站驗證、伺服器位址與網路權限。Check required setup. Review login, source settings, website verification, server address, and network permissions.
  3. 3提供可重現資訊。仍有問題時，記下發生位置、App 與 iOS 版本、裝置、來源 host、步驟、預期與實際結果，再到回報問題。Provide reproducible details. If it still fails, note the area, app and iOS versions, device, source host, steps, expected result, and actual result, then report the issue.
不要公開敏感資料：密碼、私密 token、完整 cookie、付費內容與他人個資都不應貼進 issue。Keep sensitive data private: never paste passwords, private tokens, full cookies, paid content, or other people's personal data into an issue.
